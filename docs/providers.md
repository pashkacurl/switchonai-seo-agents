# Источники, модели и доступы

Сначала выберите нужные данные, затем подключайте сервис. Установка пакета
не создаёт аккаунты, не покупает тарифы и не разрешает расходование квот.
`doctor` проверяет локальные настройки без сети. Рабочие обращения выполняются
с `--live` и ненулевым согласованным лимитом.

## Что подключать

| Источник | Поля и доступ | Что получает пакет |
|---|---|---|
| Сайт и конкуренты | HTTPS-домен; `sources.competitor_urls` для сравнения | HTML, метаданные, ссылки, robots и sitemap в пределах лимита обхода |
| Google Search Console | `sources.gsc_property`; `GSC_CLIENT_ID`, `GSC_CLIENT_SECRET`, `GSC_REFRESH_TOKEN` | Запросы и страницы своего сайта, показы, клики и средняя позиция |
| Яндекс Вебмастер | `sources.yandex_user_id`, `sources.yandex_host_id`; `YANDEX_WEBMASTER_TOKEN` | Популярные поисковые запросы своего сайта |
| Topvisor | Отдельные `topvisor_user_id`, `topvisor_project_id`, `topvisor_region_index`; `TOPVISOR_API_TOKEN` | Уже существующая история позиций; новый платный съём автоматически не запускается |
| Яндекс Метрика | `sources.metrika_counter_id`; `METRIKA_TOKEN` | Доступная статистика посещений и конверсий настроенного счётчика |
| PageSpeed Insights | `PSI_API_KEY` | Лабораторный результат и полевые данные, если API их вернул |
| Импорт позиций | `sources.measurements_import` — путь CSV | Сопоставление фактических наблюдений с сохранением источника и периода |
| Импорт GEO | `sources.geo_import` — путь JSON | Сохранённые ответы выбранных систем с вопросом, датой и провайдером |
| Telegram | `notifications.telegram_chat_id`, при необходимости `telegram_thread_id`; `TELEGRAM_BOT_TOKEN` | Отчёт и сообщения о принятых публикациях/остановках |

Имена в верхнем регистре — переменные личного `.env`. Не передавайте их значения
в чат, CSV, промпты модели, Git или диагностические скриншоты. Выдавайте доступ
только к нужному сайту. Чтение публичной документации не является проверкой
авторизации аккаунта.

Google OAuth должен разрешать чтение Search Console. Если включена отправка
sitemap, нужны права записи; не расширяйте права для одного лишь отчёта.
Владелец авторизуется сам, агент проверяет результат ограниченным обращением.
Путь к свойству GSC берётся из панели точно, включая `sc-domain:` для доменного
свойства. Идентификатор счётчика Метрики, проекта Topvisor и сайта Вебмастера —
разные значения.

## Как читать измерения

GSC ограничивает выдачу внутренними условиями и не гарантирует все строки.
В пакете дополнительно ограничен размер выборки. Это данные видимости своего
сайта, а не полный спрос рынка. Средняя позиция имеет собственный смысл и не
смешивается с отдельным SERP-срезом. [Документация Search Analytics](https://developers.google.com/webmaster-tools/v1/searchanalytics/query).

Вебмастер возвращает популярные запросы, по которым сайт показывался в поиске.
Эти показатели не являются частотностью Wordstat. Новый сайт может ещё не иметь
истории; начальная очередь берётся из ранее собранной семантики.
[Документация популярных запросов](https://yandex.ru/dev/webmaster/doc/ru/reference/host-search-queries-popular).

Для сравнения позиций нужны одинаковые источник, поисковая система, регион,
устройство, глубина и тип метрики, а также сопоставимые периоды. «Не найден
в заданной глубине» не превращается в придуманную позицию. Исторические CSV
и GEO-ответы обозначаются как предоставленные данные, а не новый съём.

Полевые показатели PSI и лабораторный тест — разные наблюдения. Google сообщает
о планируемом прекращении выдачи полевых данных в PSI; их отсутствие не равно
нулю и не подтверждает хорошую скорость. Для отдельной интеграции полевых данных
можно рассмотреть CrUX. [Документация PSI](https://developers.google.com/speed/docs/insights/v5/get-started).

## Модель фоновой работы

| Вариант | Настройка | Проверка перед включением |
|---|---|---|
| Anthropic API | `model.provider: "anthropic"`, доступная `model.name`, `ANTHROPIC_API_KEY` | Модель поддерживает используемый формат JSON Schema; пробный вызов укладывается в лимит |
| Codex CLI | `model.provider: "codex"`, `model.name`, `model.codex_executable` | CLI доступен и авторизован у пользователя, под которым выполнится задание; поддерживает необходимые флаги |

Модель не выбирается по устаревшему названию из примера. Агент проверяет варианты
в аккаунте и согласует выбор. Anthropic-адаптер передаёт JSON Schema через
`output_config.format`; успешная проверка структуры не доказывает фактическую
достоверность текста. [Structured outputs](https://platform.claude.com/docs/en/build-with-claude/structured-outputs).

Codex запускается одноразово в отдельном временном каталоге с read-only sandbox
и структурированным выходом. Окружение очищается от ключей остальных сервисов.
Наличие Codex на компьютере владельца не означает, что он авторизован на сервере
расписания. [Неинтерактивный режим Codex](https://learn.chatgpt.com/docs/non-interactive-mode).

Перед моделью поставлен предел размера входа, числа вызовов и резервируемого
максимального выхода. Эти величины не являются точным биллингом. Проверьте
тариф, квоты аккаунта и денежные ограничения у поставщика. После тайм-аута
платный вызов не повторяется автоматически в той же стадии.

У Anthropic `max_output_tokens` передаётся как `max_tokens`. Для Codex CLI это
только резерв внутреннего счётчика: CLI не получает жёсткий предел токенов
ответа. Этот резерв не ограничивает фактическое потребление или стоимость.
Для строгого бюджета используйте API с лимитами на стороне провайдера.
Read-only sandbox не запрещает чтение всех доступных учётной записи файлов:
запускайте Codex на выделенной учётной записи без чужих секретов и документов.
Встроенный API-адаптер не предоставляет модели инструменты.

## Уведомления после публикации

Telegram отправляется только настроенному получателю. В ответе требуется
подтверждение сообщения; при разрыве связи результат остаётся неопределённым,
пока владелец не проверит чат. [Telegram Bot API](https://core.telegram.org/bots/api).

По отдельному выбору доступны IndexNow, запрос переобхода Яндекса и отправка
sitemap в GSC. Ключ IndexNow и файл проверки размещаются на своём домене.
Уведомление означает принятие запроса сервисом, а не гарантированную индексацию.
[Протокол IndexNow](https://www.indexnow.org/documentation).

Дата сверки перечисленных официальных страниц: 2026-11-06. Содержание страниц
проверено; действующие ключи, тарифы пользователя и рабочие ответы API этим
чтением не проверялись. При изменении API сверяйте документацию и контракт
адаптера до следующего согласованного вызова.
