# Проверка v0.1.0

Дата: 2026-11-06. Первый публичный выпуск для установки с контрольной приёмкой.

Подтверждено локально: 56 тестов стандартной библиотеки на Windows / Python
3.12.14; синтаксис, схемы ответов модели, ссылки, отсутствие частных файлов и
секретов, нулевые дневные лимиты и выключенное расписание. Полный перечень и
ограничения — в [отчёте испытаний](test-findings.md).

Офлайн-демо проходит от импорта темы до квитанции искусственного сайта; повтор
не развёртывает материал заново. Проверены настоящие команды CLI, резерв SQLite
и Git-коммиты в искусственном временном репозитории. Дополнительно сетевой
адаптер получил реальный HTTPS 200 от `https://www.example.com/`: конечный URL
совпал, ответ содержал HTML. Ключи, платные API и сообщения не использовались.

Не верифицировано: рабочие ответы пользовательских API, модельный результат
на реальной фактуре, Linux/cron, SSH и сборка/публикация настоящего Next.js-сайта.
Эти проверки выполняются при установке по README, до включения автоматического
режима. Поэтому релиз обозначен предварительным; прохождение фикстур не
объявляется испытанием чужого производственного окружения.

Границы адаптеров: статический HTML-checker требует указанный каталог экспорта;
SSR получает собственную команду приёмки. SVG-схемы встроены, фотографии и
генераторы изображений не подключаются автоматически. Для Codex счётчик
резервируемого выхода не является жёстким пределом фактических токенов/стоимости.
Кандидаты из панелей требуют проверки и пополнения очереди: модель не делает
новый запрос измеренным спросом.

Проверки выпуска:

```sh
python -B scripts/check_package.py
python -B -m unittest discover -s tests -q
python -B seo.py demo
python -B scripts/build_release.py
```

ZIP и SHA256SUMS создаются в единственном каталоге `dist/`. Пользовательские
профили не включаются. Временные данные тестов удаляются; постоянные процессы
не запускаются.
