# Проверка переносимого пакета

Дата: 2026-11-06. Среда: Windows, Python 3.12.14, стандартная библиотека.

**Подтверждено:** команда `python -B -m unittest discover -s tests -q` завершилась успешно: 56 тестов, 12,313 с, `OK`. Это результат локальных испытаний на искусственных данных. Перед выпуском после последующих изменений требуется повторный запуск этой же команды.

## Исправления, найденные испытаниями

Все перечисленные дефекты обнаружены при проверке ранней рабочей версии, исправлены основным разработчиком и закрыты регрессионными тестами. Это не список неисправностей текущей проверенной версии.

1. Запись текста через системные переводы строк Windows меняла байты относительно хеша: согласование и восстановление считали собственный файл изменённым. Статья, SVG и резерв теперь записываются побайтно. Основание: [материализация](../seo_agents/content.py), [адаптер сайта](../seo_agents/sitebridge.py).
2. Откат мог затереть поздние правки владельца. Теперь сначала проверяются все текущие хеши, затем выполняется восстановление. Основание: `Site.restore`, тест `test_rollback_preserves_later_owner_changes`.
3. Многострочные MDX-выражения, reference-ссылки и переносы в alt обходили прежние проверки. Ужесточены Markdown и frontmatter-контракты. Основание: `check_article`, `Site.dispatch` и тесты безопасного содержимого.
4. Уникальность slug запрещала содержательное обновление своей же страницы. Ограничение относится к новой странице; refresh сохраняет владельца страницы, кластер и slug. Основание: [состояние](../seo_agents/core.py), `import_topics`.
5. Неполные dimensions GSC вызывали `IndexError` вне обработки модуля. Теперь источник получает статус «Не проверено», остальные части отчёта сохраняются. Основание: [сбор отчёта](../seo_agents/monitoring.py).
6. Проверка PID через `os.kill(pid, 0)` опасна на Windows. Используется отдельная проверка существования процесса без сигнала; тест запрещает вызов `os.kill` на этой ветке. Основание: `process_exists`, [официальное описание os.kill](https://docs.python.org/3/library/os.html#os.kill), проверено 2026-11-06. Опасный вызов в испытании не выполнялся.
7. При redirect учитываются авторизационные заголовки, включая `X-Goog-Api-Key` и Cookie. Основание: [Redirects](../seo_agents/network.py), `test_authorized_requests_cannot_forward_headers_through_redirect`.

## Что эта проверка не подтверждает

- Авторизация и ответы реальных Anthropic, Codex, поисковых панелей, Topvisor, Метрики, PSI, Telegram и IndexNow не испытывались. Вместо них использованы явно обозначенные подставные ответы и модели.
- Настоящий Next.js build, SSH, развёртывание, HTTPS, оформление страниц и живой откат не выполнялись. Команды build/deploy/acceptance в испытаниях заменены функциями; Git испытывался отдельно настоящими локальными командами.
- Синтаксически допустимая цитата сама по себе не доказывает вывод из неё. Семантическая точность текста и качество редакторской модели требуют приёмки владельцем на его материалах.
- Это не полный аудит сетевой изоляции. Проверка DNS перед запросом не является доказательством защиты от всех вариантов DNS rebinding; на сервере остаются нужны ограничения исходящего доступа и доверенные источники.
- Испытана Windows-ветка. Linux cron, системный часовой пояс и файловые блокировки POSIX требуют отдельной проверки на целевом сервере.

## Ресурсы проверки

Использованы уже установленные Python и Git. Запускались только завершающиеся процессы CLI/Python/Git. Все синтетические профили, SQLite-копии, ZIP и один искусственный Git-репозиторий создавались в `TemporaryDirectory` и удалены после тестов. Clone, worktree, установки пакетов, серверы, фоновые процессы, cron и реальные исходящие сообщения не создавались. Ничего не оставлено работать.
