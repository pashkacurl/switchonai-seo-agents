# Switch On AI · SEO-агенты

**Павел Лещенко · Switch On AI**

Пакет для сайта с блогом: собирает SEO-наблюдения, готовит статьи из утверждённой семантики и выпускает их по согласованным правилам. Первый материал проходит просмотр владельцем и контрольную публикацию. После этого можно включить автоматическую работу.

Настройку выполняет ваш Codex или Claude Code. Дополнительный скилл не нужен. Для программы достаточно Python 3.11 или новее; её Python-модули используют стандартную библиотеку. Для генерации нужен отдельно настроенный Anthropic API или авторизованный Codex CLI. Подписка на приложение и доступ к API — разные способы оплаты.

## Начните с двух заданий агенту

Скачайте ZIP выбранного релиза из [репозитория](https://github.com/pashkacurl/switchonai-seo-agents), распакуйте и откройте папку в Codex или Claude Code. Рядом держите документы сайта: паспорт бизнеса, карту страниц, семантику и сведения о публикации. Личный профиль создаётся отдельно от публичного кода.

**1. Подключить наблюдение**

```text
Прочитай README.md, AGENTS.md и docs/quickstart.md этого пакета.
Настрой SEO-наблюдение для моего сайта по уже имеющимся документам.
Используй существующие Python и инструменты. Создай отдельный личный
профиль, объясни только недостающие поля и подготовь безопасный .env.
Ключи я введу самостоятельно. Сначала выполни офлайн-демо и doctor.
Согласуй источники, лимиты, получателя отчёта и проверки доступов.
После согласования получи первый настоящий отчёт. Покажи, какие
проверки выполнены, какие недоступны и на каких данных основаны выводы.
Расписание включай только после моей приёмки первого результата.
```

**2. Подготовить пробную статью и автоматический выпуск**

```text
Прочитай docs/site-adapter.md и docs/recovery.md. Используй мой паспорт,
семантику и карту страниц; повторно собирать их с нуля не нужно.
Настрой выпуск в мой блог и импортируй подтверждённые свободные кластеры.
Согласуй реального автора, категории, стиль, источники, темп и бюджет.
Подготовь одну статью: источники → бриф → текст → редактура → медиа.
Покажи материал и замечания мне. После моего одобрения выполни контрольную
публикацию и проверь живую страницу, версию, sitemap и изображения.
После моей приёмки включи автоматический режим в согласованных границах.
Неподтверждённые факты, новые неразрешённые источники и конфликты страниц
должны останавливать соответствующую статью. Покажи статус и команду паузы.
```

## Что получится

- Отчёты с результатами обхода сайта и доступных поисковых панелей; отсутствующий источник отмечается как непроверенный.
- Очередь статей с привязкой к запросам, кластеру и странице. Поисковые кандидаты попадают на проверку, а не сразу в публикацию.
- Бриф, статья, реестр утверждений и источников, редакторская проверка и при необходимости схемы SVG.
- Последовательный выпуск с квитанцией сайта, проверкой опубликованной версии и отдельной доставкой уведомлений.
- Понятная пауза и продолжение после сбоя без повторной генерации уже сохранённых этапов.

Первый адаптер предназначен для блога на Next.js с файловыми статьями. Агент должен согласовать контракт и команды сборки с вашим проектом. WordPress и другие CMS требуют своего адаптера; универсальную установку одной командой этот выпуск не обещает.

## Что важно при первом запуске

Все дневные лимиты внешней работы изначально равны нулю, расписание выключено. `demo` работает офлайн. `doctor` проверяет локальную готовность, а успешную авторизацию и публикацию подтверждает только согласованный рабочий запуск.

Автоматический редактор помогает найти ошибки, но не доказывает истинность всех утверждений. Автоматический выпуск разрешайте для подходящих тем и проверяемых источников. Измерения, просмотры, позиции, индексация и цитирование в ИИ-ответах не гарантируются.

В пакет не входят личные сайты, ключи, закрытые учебные материалы и чужие книги. Условия переработки исходного шаблона сохранены в [NOTICE.md](NOTICE.md); код распространяется под [MIT](LICENSE).
